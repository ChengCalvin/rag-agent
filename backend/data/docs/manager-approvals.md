# Manager Approvals and Discount Overrides

This document is for store managers and above. It is not for general staff. All figures are synthetic.

## Discount overrides

A store manager may approve a discount override of up to 15 percent on a single transaction. Overrides above 15 percent need regional manager approval. Record the reason code in the till system.

## Refund approvals

A store manager may approve a refund outside the return window up to a value of 200 as a goodwill gesture, once per customer per quarter. Larger amounts go to the regional manager.

## Goodwill log

Every override and goodwill refund is entered in the goodwill log the same day. The regional manager reviews the log monthly.
