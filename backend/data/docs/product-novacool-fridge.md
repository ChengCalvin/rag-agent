# NovaCool Mini Fridge Placement Guide

The NovaCool is a synthetic example product used for this prototype.

## Where to place the fridge

Leave clear space around the unit so the compressor can shed heat. Do not place it in a closed cabinet.

## Clearance diagram

```
        15 cm
   +--------------+
   |              |
 8 |  NovaCool    | 8
 cm|  mini fridge | cm
   |              |
   +--------------+
        10 cm
   (back wall on the right side)
```

## First use

Let the fridge stand upright for 4 hours before switching it on. Set the dial to the middle setting for the first day.
