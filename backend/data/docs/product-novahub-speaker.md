# NovaHub Smart Speaker Setup Guide

The NovaHub is a synthetic example product used for this prototype.

## Connecting the speaker

Plug the speaker into mains power, wait for the white light to pulse, then pair it from the NovaHub app. Keep the speaker within 10 metres of the home router during setup.

## Connection layout

```
 [ Phone app ] --bluetooth--> [ NovaHub speaker ]
                                     |
                                   wifi
                                     |
                              [ Home router ] ---> [ Internet ]
```

## Troubleshooting

If the light stays red, hold the top button for 10 seconds to reset the speaker and repeat the pairing steps.
